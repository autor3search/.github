# .github

Organization-level files for [autor3search](https://github.com/autor3search).

| path | what it is |
| --- | --- |
| `profile/README.md` | what renders on the organization page |
| `profile/autor3search.png` | the chain mark used on that page and on [autor3search.dev](https://autor3search.dev) |
| `branding/avatar.svg` | the organization avatar — the loop, mostly kept, one experiment discarded, a candidate on the bench |
| `branding/avatar.png` | the same, rasterized to 512px, which is what GitHub wants |

GitHub has no API for an organization's avatar, so `branding/avatar.png` has to
be uploaded by hand, once:
**Settings → Profile → Upload new picture**, at
<https://github.com/organizations/autor3search/settings/profile>.
